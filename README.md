# ELRD

iPad-App für Einsatzleiter im Rettungsdienst und Katastrophenschutz: Patientensichtung, Organisation von Abschnitten und Einheiten, Lagekarte, Einsatztagebuch und frei konfigurierbare PDF-Berichte.

Neubau von ELRDRG in SwiftUI, vorbereitet für einen Mehrbenutzer-Modus.

- Funktionsumfang: [`docs/FUNKTIONEN.md`](docs/FUNKTIONEN.md)
- Architektur: [`docs/ARCHITEKTUR.md`](docs/ARCHITEKTUR.md)
- Entscheidungen: [`docs/ENTSCHEIDUNGEN.md`](docs/ENTSCHEIDUNGEN.md)
- Fortschritt: [`docs/FORTSCHRITT.md`](docs/FORTSCHRITT.md)

**Voraussetzungen:** Xcode 16 oder neuer, iPadOS 17.0+.
